\chapter{Introducción}
ASTRA CLOUD es una plataforma cinematográfica distribuida desarrollada para el curso de Cloud Computing. El proyecto separa identidad, catálogo, comunidad, interacciones, sesiones de cine y analítica en servicios independientes, con responsabilidades claras y tecnologías adecuadas a cada dominio.

La solución integra APIs REST, WebSocket para sesiones en vivo, persistencia relacional y documental, contenedores Docker y una arquitectura AWS definida como código. También incluye un pipeline que extrae datos operacionales, los serializa en CSV y los deposita en Amazon S3 para analizarlos con Athena.
