\chapter{Consideraciones de costos}
El costo depende principalmente de las cuatro instancias EC2 \texttt{t3.medium}, EBS, ALB, API Gateway, S3 y el volumen procesado por Athena. Glue y la transferencia de datos pueden generar cargos cuando se habiliten sus recursos. La separación de ingesta y el uso de Athena permiten ajustar el gasto analítico al volumen de consultas, sin mantener un clúster analítico permanente.
