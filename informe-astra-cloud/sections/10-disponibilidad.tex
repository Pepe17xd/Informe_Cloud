\chapter{Disponibilidad y balanceo}
La arquitectura ubica dos instancias de producción en subredes de zonas de disponibilidad distintas. El balanceador revisa periódicamente si cada instancia responde y, si una deja de hacerlo, no le envía solicitudes hasta que vuelva a estar disponible. No se configur un Auto Scaling Group; la disponibilidad adicional depende de dos instancias fijas.
La base de datos y los procesos de carga se ejecutan en una sola instancia. Cinema Session guarda el estado en la memoria de cada proceso, por lo que una sesión no se comparte automáticamente entre las dos instancias.
