\chapter{Conclusiones}
ASTRA CLOUD se desarrolló como una plataforma cinematográfica dividida en seis microservicios. Identity, Catalog, Community, Interaction, Cinema Session y Analytics se encargan de partes diferentes de la aplicación, por lo que cada una puede usar la tecnología que necesita.

Para guardar la información se usaron PostgreSQL para las cuentas y el catálogo, MySQL para la parte social y MongoDB para las interacciones. Esta combinación de distintas bases de datos se conoce como persistencia políglota. Docker y Docker Compose ayudan a ejecutar los servicios de la misma forma en cada entorno, y CloudFormation define la VPC, las EC2, API Gateway, VPC Link, el ALB y S3. Finalmente, el flujo PostgreSQL/MySQL/MongoDB $\rightarrow$ CSV $\rightarrow$ S3 $\rightarrow$ Athena permite consultar los datos sin cargar las bases de datos que usa la aplicación.
