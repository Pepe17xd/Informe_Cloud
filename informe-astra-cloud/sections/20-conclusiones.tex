\chapter{Conclusiones}
ASTRA CLOUD permitió implementar una plataforma cinematográfica organizada en seis microservicios con responsabilidades diferenciadas. Identity, Catalog, Community, Interaction, Cinema Session y Analytics colaboran mediante interfaces definidas, lo que mantiene separadas la autenticación, el catálogo, la interacción social, las sesiones compartidas y la consulta analítica.

La solución adopta persistencia políglota: PostgreSQL respalda las cuentas y el catálogo, MySQL concentra la información comunitaria y MongoDB conserva las interacciones. Esta elección responde al tipo de información administrada por cada servicio y se complementa con Docker y Docker Compose para reproducir los entornos de ejecución.

El despliegue se describe con CloudFormation e integra VPC, instancias EC2, API Gateway, VPC Link, ALB y S3. Además, el flujo PostgreSQL/MySQL/MongoDB $\rightarrow$ CSV $\rightarrow$ S3 $\rightarrow$ Athena permite analizar los datos extraídos sin trasladar esa carga a las bases operativas. En conjunto, el proyecto demuestra la integración de servicios, persistencia, despliegue cloud y analítica dentro de una arquitectura coherente para el alcance académico planteado.
