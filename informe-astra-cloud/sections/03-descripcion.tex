\chapter{Descripción del proyecto}
\section{Problema y solución}
Una plataforma cinematográfica debe gestionar películas, cuentas, comunidades, reacciones y sesiones compartidas. En ASTRA CLOUD estas tareas se repartieron entre varios servicios: Catalog guarda los datos de las películas; Identity registra cuentas y emite tokens; Community maneja perfiles, clubes y salas; Interaction guarda reseñas, likes, listas e historial; Cinema Session coordina las sesiones temporales; y Analytics consulta los datos reunidos en S3.
\section{Alcance}
El proyecto contiene las seis APIs de backend, sus configuraciones de contenedor, los procesos que cargan datos a S3 y la plantilla de infraestructura. Las operaciones normales usan REST; Cinema Session usa WebSocket para enviar eventos de reproducción, membresía y chat.
\section{Capa cliente}
ASTRA CLOUD cuenta con una aplicación web desplegada en AWS Amplify. Desde ella se puede iniciar sesión, explorar el catálogo, ver el detalle de una película, revisar clubes, editar el perfil y participar en órbitas compartidas. La interfaz consume las APIs publicadas por API Gateway y archivos estáticos de S3. El código fuente del frontend y la configuración de Amplify no están incluidos en este proyecto, pero la aplicación desplegada se explica en el Capítulo~\ref{chap:frontend}.
