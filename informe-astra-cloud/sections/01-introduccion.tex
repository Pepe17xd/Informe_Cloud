\chapter{Introducción}
ASTRA CLOUD es una plataforma cinematográfica desarrollada para el curso de Cloud Computing. La aplicación se dividió en servicios independientes para identidad, catálogo, comunidad, interacciones, sesiones de cine y analítica. Cada uno se encarga de una función específica.

El proyecto usa APIs REST, WebSocket para las sesiones en vivo, Docker e infraestructura AWS definida como código. Para guardar la información se utilizan bases de datos relacionales y MongoDB. También se implementó un proceso que extrae datos, los guarda en archivos CSV en Amazon S3 y los consulta con Athena.
