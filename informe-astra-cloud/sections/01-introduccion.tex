\chapter{Introducción}
Las plataformas digitales de contenido integran diferentes funciones, como la gestión de usuarios, catálogos, comunidades, interacciones y sesiones compartidas. A medida que estas funcionalidades aumentan, también surge la necesidad de organizarlas de manera que puedan desarrollarse y mantenerse de forma independiente.

A partir de esta necesidad se desarrolló ASTRA CLOUD, una plataforma cinematográfica basada en una arquitectura de microservicios. El proyecto integra seis servicios con responsabilidades específicas y utiliza tecnologías cloud para su comunicación, almacenamiento, despliegue y análisis de datos. En este informe se presenta la arquitectura implementada y los principales componentes que permiten su funcionamiento.
