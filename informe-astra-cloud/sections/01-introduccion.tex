\chapter{Introducción}
ASTRA CLOUD es una plataforma cinematográfica distribuida desarrollada para el curso de Cloud Computing. El proyecto separa la identidad, el catálogo, la comunidad, las interacciones, las sesiones de cine y la analítica en servicios independientes. Cada servicio se encarga de un dominio específico.

La solución integra APIs REST, WebSocket para las sesiones en vivo, persistencia relacional y documental, contenedores Docker e infraestructura AWS definida como código. También incluye un pipeline que extrae datos operacionales, los guarda en archivos CSV y los deposita en Amazon S3 para analizarlos con Athena.
