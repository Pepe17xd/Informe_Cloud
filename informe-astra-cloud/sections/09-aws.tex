\chapter{Infraestructura AWS}
\section{Red y cómputo}
CloudFormation define una VPC \texttt{10.0.0.0/16}, dos subredes públicas en zonas de disponibilidad diferentes, Internet Gateway, rutas y DNS interno. Incluye dos EC2 de producción, una para bases de datos y otra para ingesta, todas \texttt{t3.medium} con volúmenes gp3 de 20 GiB. La zona privada Route 53 \texttt{proycloud.local} resuelve \texttt{db.proycloud.local}.
\section{Exposición de servicios}
Un ALB interno contiene listeners y grupos destino para los seis puertos. Seis HTTP API Gateway conectados mediante VPC Link centralizan la entrada. Cada grupo consulta \path{/health} cada 30 segundos y distribuye tráfico a las dos EC2 de producción.
