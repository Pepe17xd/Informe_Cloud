\chapter{Infraestructura AWS}
\section{Red y cómputo}
CloudFormation define la red en AWS: una VPC \texttt{10.0.0.0/16}, dos subredes públicas en zonas de disponibilidad diferentes, Internet Gateway, rutas y DNS interno. También crea dos EC2 de producción, una para bases de datos y otra para ingesta, ambas \texttt{t3.medium} con volúmenes gp3 de 20 GiB. La zona privada de Route 53 \texttt{proycloud.local} resuelve \texttt{db.proycloud.local}.
\section{Exposición de servicios}
Las solicitudes llegan por seis HTTP API Gateway conectados al ALB interno mediante VPC Link. El ALB tiene listeners y grupos destino para los seis puertos. Cada 30 segundos revisa la ruta \path{/health} de los servicios y envía el tráfico a las EC2 que estén respondiendo.
