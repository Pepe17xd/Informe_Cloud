\chapter{Seguridad}
\section{Identidad y acceso}
Identity se encarga del registro y del inicio de sesión. Las contraseñas se guardan como hashes y el servicio emite JWT HS256. Community, Interaction y Cinema Session validan el token antes de atender rutas protegidas, sin almacenar las contraseñas de los usuarios.
\section{Red y configuración}
La plantilla define grupos de seguridad para ALB, producción y bases de datos. PostgreSQL, MySQL y MongoDB aceptan conexiones desde el grupo de producción. Secretos y contraseñas se suministran como parámetros \texttt{NoEcho} y variables de entorno; el bucket de pósters cuenta con cifrado SSE-S3.
\section{Consideraciones}
Para el entorno académico se definieron subredes públicas, SSH abierto y lectura pública para el bucket exclusivo de pósters. En un entorno de producción se debería restringir SSH y CORS, usar TLS y administrar los secretos con Secrets Manager o SSM.
