\chapter{Infraestructura como código}
La infraestructura de ASTRA CLOUD se definió con AWS CloudFormation en el archivo \texttt{proycloud-infrastructure.yaml}, ubicado en \path{../infrastructure/aws/}. La plantilla declara la red, los grupos de seguridad, las instancias EC2, el DNS privado, el ALB, los grupos destino, API Gateway con VPC Link y el bucket de medios. Sus bloques \texttt{UserData} preparan las instancias con Docker y Docker Compose, por lo que la topología de despliegue queda versionada.
