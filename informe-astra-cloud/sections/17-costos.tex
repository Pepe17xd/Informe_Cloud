\chapter{Consideraciones de costos}
El costo depende principalmente de las cuatro instancias EC2 \texttt{t3.medium}, EBS, ALB, API Gateway, S3 y el volumen de datos que procesa Athena. Glue y la transferencia de datos también pueden generar cargos cuando se habiliten. Como Athena consulta los archivos cuando se necesita, no es necesario mantener un clúster analítico permanente.
