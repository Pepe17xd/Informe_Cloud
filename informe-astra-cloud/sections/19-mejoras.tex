\chapter{Mejoras futuras}
Como mejoras futuras, se podría agregar Redis para compartir el estado de Cinema Session, un servicio administrado de secretos, monitoreo y alertas con CloudWatch, respaldos, Auto Scaling Groups y CI/CD con pruebas y análisis de imágenes. En la parte analítica, los procesos de Glue que detectan la estructura de los archivos, las particiones y una programación de cargas permitirían ejecutar el proceso de forma periódica.
